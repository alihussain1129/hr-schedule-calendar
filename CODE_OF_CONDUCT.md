# Code of Conduct

We aim to maintain a respectful, inclusive, and helpful environment.

## Expected behavior

- Respect differing viewpoints and experiences.
- Give constructive feedback.
- Keep discussions focused on technical quality and user value.

## Unacceptable behavior

- Harassment or abusive remarks.
- Personal attacks or discrimination.
- Disruptive behavior in issues or pull requests.

## Enforcement

Project maintainers may take action when behavior violates these standards.
