# HR Schedule Calendar

HR Schedule Calendar is a React and TypeScript scheduling dashboard built for managing team shifts, events, and resource planning.

## Key features

- Weekly, daily, monthly, and yearly calendar views
- Interactive event cards and schedule details
- Create schedules from empty time slots
- Date navigation and native date picker
- Responsive layout for desktop and mobile

## Tech stack

- React 19
- TypeScript
- Vite
- CSS

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Production build

```bash
npm run build
```
